# Propósito del Proyecto

El propósito de este proyecto es servir como una plataforma práctica para el aprendizaje y dominio del flujo de trabajo colaborativo en Git y GitHub. A través del desarrollo de un sistema simple de gestión de tareas y notas, el proyecto permite ejercitar la creación de ramas, gestión de proyectos como propietario y colaborador, resolución de conflictos y envío de Pull Requests.
