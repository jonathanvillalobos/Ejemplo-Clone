# Funcionalidades Previstas

A continuación se enlistan las funcionalidades planificadas para el proyecto:

* **Registrar tareas:** Permitir la creación e ingreso de nuevas tareas pendientes.
* **Consultar tareas:** Visualizar el listado completo de tareas registradas y sus detalles.
* **Modificar tareas:** Editar el título, descripción o detalles de una tarea existente.
* **Marcar tareas como terminadas:** Actualizar el estado de una tarea a completada.
* **Eliminar tareas:** Remover tareas del listado de forma permanente.
* **Registrar notas:** Crear anotaciones breves o información adicional independiente de las tareas.
